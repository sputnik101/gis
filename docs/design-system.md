# Своя ГИС — дизайн-система v3

Источник правды — прототип (`index.html`). В Figma те же значения — переменные «ГИС · Цвета», «ГИС · Размеры», текстовые стили «ГИС/…» и тени; их ставит плагин `figma-plugins/design-system`. Поменял токен — поменяй в обоих местах.
