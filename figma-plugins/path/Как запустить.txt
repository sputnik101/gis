Плагин «Своя ГИС — путь: поиск → маршрут» (24.11.2026)

Нужен плагин v2 (переменные, стили, компоненты). Тени (depth v3) — по желанию.
Запуск: Plugins → Development → Import plugin from manifest… → manifest.json → запустить.

Страница «ГИС · Путь: поиск → маршрут», три ряда экранов 360×800:
  Общее:     0 · Первый запуск (только «Куда?» и карта) · 1 · Поиск с моими маршрутами и недавними · 2 · Ввод «Бауман»
  Вариант А: А3 место в шторке (коротко: метро 33 · такси 34 · пешком 2 ч) → А4 шторка раскрыта в способы → А5 «Прибыть к 9:00»
  Вариант Б: Б3 карточка места на карте → Б4 отдельный экран «Как добраться» → Б5 «Прибыть к 9:00»

Переходы: поиск → ввод; «Работа» → сразу способы к 9:00 (А5); результат → А3;
А3 «Маршрут» → А4; кнопка времени А4 ⇄ А5; Б3 «Как добраться» → Б4; время Б4 ⇄ Б5.
Старты прототипа: «Поиск», «Вариант А», «Вариант Б».
