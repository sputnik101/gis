Плагин «Своя ГИС — прогноз v4» (этап 2, 22.11.2026: метро по интервалам, плашки, без дублей итога)

Нужен плагин v2 (переменные, стили, компоненты). Плагин теней (depth v3) — по желанию.
Запуск: Plugins → Development → Import plugin from manifest… → manifest.json → запустить.

На странице «ГИС · Компоненты» появится «Карточка варианта · v2»:
  Итог = Надёжно / Стабильно / Есть риск / Риск из-за пробок / Зависит от пробок / Бывает дольше / Скорее опоздаешь / Не успеешь
  (зелёный — надёжно, оранжевый — риск, красный — опоздание), Выбрана = Да / Нет.
  Справа главный ответ: «Подпись сверху / Главное / Подпись снизу» — например «выйди до / 8:27 / ещё 7 мин».
  Переключатели: «Лучше всего», «Показать пилюлю 2», «Показать пилюлю 3»; иконка меняется.
  Старая «Карточка варианта» остаётся — её можно удалить, если не нужна.

Новая страница «ГИС · Прогноз v4», 7 экранов 360×800 (цифры — из живого прототипа):
  P1 · Как успеть к 9:00 — «Лучше всего: метро, выйди до 8:23, ещё 3 мин»
  P2 · Если выйти в 8:45 — «будешь в», «самое позднее», цель «к 9:00 опоздаешь на…»
  P3 · Когда? — шторка выбора времени
  P4 · Маршрут: метро — «Выходи до 8:23», ориентиры белые, предупреждения оранжевые
  P5 · Маршрут: такси — «Вызывай сейчас» + пилюля «риск из-за пробок»
  P6 · Вызвать такси? — подтверждение перед платным действием
  P7 · К 8:30 уже не успеть — действия: показать к 9:00, самый быстрый, предупредить

Переходы: метро → P4, такси → P5 → P6; кнопка времени → P3; «Готово», «Отмена», шапка маршрута → назад.
Повторный запуск создаст страницу с номером «(2)».
