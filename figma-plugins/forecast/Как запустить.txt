Плагин «Своя ГИС — прогноз v2»

Нужен плагин v2 (переменные, стили, компоненты). Плагин теней (depth v3) — по желанию: если он уже запускался,
карточки получат стиль «ГИС/Карточка на светлом».

Запуск: Plugins → Development → Import plugin from manifest… → manifest.json → запустить.

Что появится:
  На странице «ГИС · Компоненты» — компонент «Карточка варианта»:
    Итог = Надёжно / Стабильно / Есть риск / Зависит от пробок / Скорее опоздаешь / Не успеешь,
    Состояние = Обычная / Выбрана; тексты — свойства, «выйти до» включается переключателем, иконка меняется.
  Новая страница «ГИС · Прогноз v2» с пятью экранами 360×800:
    P1 · Как успеть к 9:00 — время прибытия и запас, «в плохой день», итог цветом
    P2 · Если выйти в 8:45 — режим «Выйти в»
    P3 · Когда? — шторка выбора времени: «Прибыть к / Выйти в», быстрые чипы, колесо
    P4 · Маршрут: метро — «Выходи до 8:29», шаги с ориентирами
    P5 · Маршрут: каршеринг — состояние «скорее опоздаешь»

Переходы: карточки «Метро» и «Каршеринг» → P4 / P5; кнопка времени в заголовке («9:00 ▾», «в 8:45 ▾») → P3;
«Готово» и «Другой способ» → назад.

Повторный запуск создаст страницу с номером «(2)» — старую можно удалить.
Цифры совпадают с живым прототипом (index.html) на 22.11.2026.
